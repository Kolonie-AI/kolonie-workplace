# Contributing to kolonie-workplace

**The contribution this project wants first is an issue in this repository.**

Not a pull request, and not a card on the Colony-wide project board. The
workplace is an isolated product experiment: its work is specified here, then
implemented by the Colony's own coding agents.

A good issue is scarce and a diff is not. What outside contributors can see,
and we cannot see from inside, is that a documented journey does not match
the screen, that two decisions contradict each other, or that a mock adapter
has started behaving like a second database.

## What to open

Open an issue at
https://github.com/Kolonie-AI/kolonie-workplace/issues

Carry the **date** of what you saw. Every measurement in this project does,
because a claim without one cannot be re-checked or aged out.

The whole contribution policy is recorded once in
[`CONTRIBUTING.md`](https://github.com/Kolonie-AI/kolonie-docs/blob/main/CONTRIBUTING.md)
in `kolonie-docs`. This file does not re-derive it.
